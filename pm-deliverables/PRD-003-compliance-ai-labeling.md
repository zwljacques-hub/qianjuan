# PRD-003 · 合规与 AI 标识

> 文档版本: v1.0 · 2026-05-22
> 上游依赖: [PRD-001 双模工作台](PRD-001-dual-mode-workstation.md)、[INTEGRATION-001 AI 工具箱集成方案](INTEGRATION-001-ai-toolbox.md)

---

## 0. 文档定位

本 PRD 定义 **千卷** 在合规层面的产品形态: AI 生成内容的标识、用户协议条款、平台投稿风险提示、内容审核、申诉与数据合规。

**核心定位**: 工具合规、用户尽到自我审查义务、千卷在用户发表作品的任何风险中可主张已尽到合理告知义务。

法律意见以法务最终评估为准,本 PRD 提供产品交付物清单与默认条款建议。

## 1. 法规依据

### 1.1 现行强制性法规

| 文件 | 颁布日期 | 生效情况 | 千卷需对应的合规点 |
|---|---|---|---|
| 《生成式人工智能服务管理暂行办法》(网信办) | 2023-07 | 已生效 | 服务提供者备案、数据训练合规、用户告知义务、未成年人保护 |
| 《人工智能生成合成内容标识办法》(网信办) | 2025-03 | 已生效 | 显式标识 + 隐式标识双轨,导出/分享必须保留标识 |
| 《互联网信息服务算法推荐管理规定》 | 2022-03 | 已生效 | 推荐排序透明化(千卷工具箱内推荐工具时适用) |
| 《网络安全法》 | 2017-06 | 已生效 | 内容安全、个人信息保护底线 |
| 《个人信息保护法》 | 2021-11 | 已生效 | 用户作品作为个人创作受保护 |

### 1.2 行业规范(非强制但需对齐)

| 文件 | 适用范围 |
|---|---|
| 中国互联网协会《生成式人工智能服务标识指南》 | 标识形式参考 |
| 主流网文平台 AI 内容相关规则(2025-2026 持续收紧) | 用户投稿决策依据 |

### 1.3 风险等级

千卷属于 **"生成式 AI 服务 + 用户内容创作"双重监管对象**。一旦用户违规作品被追溯,平台 + 千卷 双方都可能被监管问询。**这意味着我们不能"以为用户能管好"**,产品必须主动履行告知与限制义务。

## 2. AI 标识嵌入(2025-03 办法核心要求)

### 2.1 双轨标识

标识办法要求**显式 + 隐式**双重标识,缺一不可:

| 类型 | 用户可见度 | 实现位置 | 千卷做法 |
|---|---|---|---|
| **显式标识** | 用户可见 | 内容本体 / 包装 / 文件头部 | 导出文件首页加 banner,正文页眉/页脚加水印 |
| **隐式标识** | 用户不可见 | 元数据 / 数字水印 | 导出文件元数据嵌入"AI 辅助生成"标识 |

### 2.2 千卷导出物的标识规范

#### 2.2.1 Markdown 导出(单章 / 全书)

```markdown
<!--
作品: 《九天剑主》
作者: ___
创作工具: AI 秘密基地 · AI 工具箱 · 千卷 v1.0
生成日期: 2026-05-22
本文件含 AI 辅助生成内容,使用 GPT-5.5 / Claude-4-7 等大语言模型
标识依据: 《人工智能生成合成内容标识办法》(国家网信办, 2025-03)
-->

# 第 12 章 · 生死战书

> 📝 **AI 辅助创作声明**: 本章节由作者使用千卷 AI 写作工具创作,
> 包含 AI 辅助生成的文字内容。读者发布或转载请保留本声明。

(正文)

---
*— 本文由「千卷」AI 写作工具辅助创作,工具地址: aisecretlair.com/toolbox/qianjuan*
```

#### 2.2.2 TXT 导出

```
=========================================
作品: 《九天剑主》第 12 章 生死战书
创作工具: AI 秘密基地 · 千卷
本文件含 AI 辅助生成内容
标识依据: 网信办 2025-03 标识办法
=========================================

(正文)

=========================================
— 本文由「千卷」AI 写作工具辅助创作
=========================================
```

#### 2.2.3 DOCX 导出(M5 后追加)

- 文件属性 → 标题 / 主题 / 备注 嵌入标识
- 文档首页 banner
- 页脚每页带"AI 辅助生成"小字

#### 2.2.4 复制到剪贴板(M5 公测保留)

复制 ≥ 200 字时弹一次性提示:

```
正在复制 AI 辅助生成内容
按《人工智能生成合成内容标识办法》要求,
发布时请保留 AI 标识。
[我已了解,继续复制]  [取消]
```

提示触发频次: 每会话首次复制时弹一次,后续不弹。

### 2.3 用户能否关闭标识?

**不能完全关闭**。允许用户:
- 选择标识样式(默认 / 简洁)
- 调整水印位置(页眉 / 页脚 / 关闭页内但保留首页 banner)

**不允许**:
- 关闭首页 banner
- 删除元数据
- 关闭隐式标识

UI 表达: **"千卷不提供去除 AI 标识的功能。这不是 bug,是合规要求。"**

### 2.4 隐式标识技术方案

| 层级 | 实现 |
|---|---|
| 元数据 | Markdown HTML 注释 / DOCX core properties / PDF metadata |
| 不可见数字水印 | M5 后接入(零宽字符嵌入文件 hash,文件大小约 +50 字节)|
| 服务器侧记录 | 每次导出记录 user_id + chapter_hash,可追溯 |

零宽字符水印实现细节(留 M5 后做技术预研,目前以元数据 + 显式标识为主)。

### 3.2 显示位置与确认机制

| 时机 | 形式 |

- 涉未成年人色情/暴力的关键词触发即拦截 + 上报

## 5. 内容审核

### 5.1 三层审核机制

| 层 | 时机 | 实现 | 处理 |
|---|---|---|---|
| L1 关键词拦截 | LLM 生成前 prompt 注入 / 生成后扫描 | 规则字典 + 正则 | 直接拒绝生成 / 删除已生成 |
| L2 模型自审 | 生成后调小模型审核 | Haiku 4.5 二次过滤 | 标记高风险,人工复核 |
| L3 人工复核 | L2 标记或用户举报 | 内部审核队列 | 删除 + 警告 / 上报 |

### 5.2 拦截关键词类别

参考网信办《互联网信息服务深度合成管理规定》:

- 涉及国家领导人、领土、民族政策
- 涉黄涉暴(尤其涉未成年人)
- 涉恐(极端主义、爆炸物、武器制造)
- 涉毒(毒品制造、滥用)
- 个人信息(电话、身份证、银行账号识别)
- 仇恨言论、地域歧视

**网文创作的特殊性**: 反派、战斗、压迫等情节是网文常见元素,不应过度拦截。L1 应有"创作语境豁免"判断,避免误伤合法网文。

### 5.3 用户举报通道

每章页面右下角持续显示"举报"按钮:

```
[🚩 举报本章节内容违规]
```

举报后进入 L3 复核队列,48 小时内反馈。

### 5.4 自动上报机制

L3 复核确认违规且严重(涉国安、涉未成年人色情等)时,按《网络安全法》要求保留证据并上报主管部门。

## 6. 数据合规

### 6.1 用户作品数据保护

| 措施 | 实现 |
|---|---|
| 加密存储 | AES-256,密钥分离管理 |
| 传输加密 | 全站 HTTPS,TLS 1.3 |
| 访问控制 | 用户作品仅本人可读,千卷员工默认无权限 |
| 审计日志 | 所有数据访问留痕,留存 6 个月 |
| 备份 | 每日增量,7 天滚动,跨可用区 |

### 6.2 数据使用边界

| 用途 | 是否需用户同意 | 默认 |
|---|---|---|
| 提供产品功能(存储、生成、审计、导出) | 注册即默认同意 | 开 |
| 脱敏聚合用于产品改进(留存率、错误率) | 注册即默认同意 | 开 |
| 用户作品文本用于训练 AI 模型 | **明确同意** | **关** |
| 内容审核 | 强制 | 开 |
| 法律法规要求的合规审查 | 强制 | 开 |

### 6.3 用户权利

用户在 `设置 → 数据与隐私` 中可随时:

- **导出**: 全部作品 / 单本作品 / 用户数据(JSON 包,含偏好/历史/账单)
- **删除**: 单本作品 / 全部作品 / 账号(账号删除 30 天后物理清除)
- **关闭授权**: "用于产品改进"开关,关闭后立即生效
- **查看访问记录**: 自己作品最近 90 天的访问日志

### 6.4 跨境数据传输

千卷服务器在境内(阿里云/腾讯云,具体待定)。
LLM 调用如使用境外模型(GPT/Claude),需走代理且**用户作品不发送原文,仅发送脱敏摘要 + 必要 context**。

**重要**: 该方案对 PRD-002 长篇一致性引擎的 context 注入策略有约束,M3 工程实施时需协调。

## 7. 申诉与下线

### 7.1 用户对千卷决定不服的申诉

| 场景 | 路径 |
|---|---|
| 内容被审核系统误判 | 设置 → 申诉 → 描述情况 + 上传截图 → 48h 内反馈 |
| 账号被封禁 | 主站客服 → 工单 → 7 天内反馈 |
| 数据导出/删除请求未响应 | 主站客服 → 工单 |

### 7.2 第三方对千卷的投诉

千卷在网站底部公示:

- 投诉邮箱: `compliance@aisecretlair.com`
- 投诉处理时限: 5 个工作日内首次响应,15 个工作日内最终处理
- 涉版权侵权: 提供权利证明 → 24 小时内紧急下线

### 7.3 监管要求的内容下线

收到监管部门要求时:
- 内容立即下线
- 通知用户
- 配合调查并保留证据
- 必要时上报全平台预防性下线

## 10. 风险与对冲

| 风险 | 影响 | 对冲 |
|---|---|---|
| 监管政策再收紧 | 千卷功能可能被要求调整 | 法务每月跟踪政策动态,产品团队预留 2 周缓冲应对 |
| 用户绕过 AI 标识(自行删除) | 千卷被追责 | 隐式标识(元数据 + 数字水印)用户难发现,可作为追溯证据 |
| 平台规则变化未及时同步 | 误导用户投稿 | 平台规则页明确"以平台最新公告为准",免责 |
| 大规模违规内容生成 | 主体责任 | L1/L2/L3 三层,任何一层异常触发告警 + 暂停服务 |
| 误判合法网文情节(战斗/反派) | 用户体验崩 | 关键词需带"创作语境豁免",并提供快速申诉 |
| 用户作品被员工内部访问 | 隐私事故 | 加密 + 默认无权限 + 访问需审批 + 审计追溯 |
| 跨境 LLM 调用导致数据出境 | 合规风险 | 用户原文不出境,只发脱敏 context;长期考虑国产模型替代 |
