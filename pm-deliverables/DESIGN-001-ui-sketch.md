# DESIGN-001 · UI 收敛草图

> 设计日期: 2026-05-22
> 目标: 8 Tab → 4 Tab,7 步 → 4 步,Auto / Studio 同源双模
> 平台: Web 桌面端(≥1280px)优先,M3 阶段补 768/375

---

## 1. 信息架构收敛

### 1.1 一级导航:8 → 4

| 旧(8 个) | 新(4 个) | 说明 |
|---|---|---|
| 章节工作台 | **写作** | 主舞台,Auto/Studio 都进这里 |
| 作品总览、已归档章节阅读 | (并入 **写作** 顶部进度条) | 不再独立 Tab |
| 真相文件、伏笔看板、角色关系 | **资料库**(右抽屉) | 三合一,默认收起 |
| 审计中心、运行记录 | **日志**(底部抽屉) | 仅出问题时弹起,平时不打扰 |
| 模型配置 | **设置** | 模型 / 账号 / 导出 / 合规 全归位 |

### 1.2 单章流程:7 → 4

| 旧(7 步) | 新(4 步) | 用户感知 |
|---|---|---|
| plan / lock | **1. 计划** | "AI 写了大纲,你来定" |
| write | **2. 写正文** | "按场景写出来" |
| audit / revise / style | **3. 打磨** | "审计 + 修订 + AI 腔降级" 全部合并 |
| settle / export | **4. 归档** | "存档,继续下一章 / 导出" |

Auto 模式下 4 步全部自动跑,用户看到的只有"正在第 N 步";Studio 模式 4 步每步可手动介入。

---

## 2. 模式切换原则

```
┌─────────────────────────────────────────────────┐
│ Auto  ──→  Studio  随时切,数据不重置           │
│ Studio  ──→  Auto  把后续步骤交还给 AI 接管     │
│                                                 │
│ 切换的是"控制权",不是"项目"                    │
└─────────────────────────────────────────────────┘
```

切换按钮位置: **顶部 logo 右侧**,模式 toggle 永远可见。

### Auto 模式关键设计

- **文字流式呈现**: SSE 边写边显示,3 秒内出第一个字
- **进度条 = 当前情绪锚点**: 不只是百分比,显示"第 X 章 · 卷名 · 当前步骤"
- **输入框是"自然语言指令"**: 不需要懂工作流,直接说想法。底层翻译成对应 agent 调用
- **暂停 / 接管 / 重写 / 下一章** 四个动作覆盖 95% 场景
- 资料库 / 日志 默认收起,只在需要时弹

### Studio 模式关键设计

- **左侧 4 入口 + 章节列表**: 极简,旧 8 Tab 全部归到中间面板或右抽屉
- **顶部 4 步进度条**: 永远可见,点任一步可回退/跳转(Auto 不可,Studio 可)
- **中央三段**: 计划 → 场景卡 → 正文编辑器,从上到下一条流水线
- **打磨结果实时**: 审计 + 风格分数 + 问题清单合并在最下方一个面板,不再分开
- **资料库右抽屉**: 真相 + 伏笔 + 角色 三合一,默认半收起,鼠标 hover 边缘展开
- **日志底部抽屉**: 默认折叠为一行最新状态,点击展开完整 trace

## 5. 关键交互细节

### 5.1 Auto → Studio 切换

| 触发 | 行为 |
|---|---|
| 用户点切换 | 当前章节状态保留;Studio UI 自动定位到 AI 当前停留的步骤 |
| AI 正在生成中 | 不中断,Studio 显示"AI 正在写场景 3"灰态,用户可点暂停 |
| 用户在 Auto 输入框打了指令 | 切到 Studio 后,该指令变成"Director 备注"显示在计划面板顶部 |

### 5.2 Studio → Auto 切换

| 触发 | 行为 |
|---|---|
| 用户点切换 | 弹出确认: "把后续步骤交给 AI 继续?" |
| 确认后 | AI 从当前步骤接续,Auto 主屏显示"AI 接管中" |
| 4 步未走完 | AI 跑完剩余步骤,跑完通知用户 |

### 5.3 章节归档与下一章

- **Auto 模式**: 第 4 步「归档」自动完成,自动开始第 N+1 章
- **Studio 模式**: 第 4 步完成后弹出"继续下一章 / 暂停 / 导出"3 个按钮
- **导出**: 全部经过合规处理(嵌入 AI 标识,见 PRD-003)

### 5.4 输入框自然语言路由(Auto 模式核心)

用户在 Auto 输入框打字 → 后端做 intent 分类 → 路由到对应 agent:

| 意图 | 例子 | 路由到 |
|---|---|---|
| 修改剧情 | "陈玄不要这么快服软" | Planner.adjust |
| 加场景 | "中间加一段苏寒回忆" | Scene Writer.insert |
| 改风格 | "更口语化一点" | Style.adjust |
| 改设定 | "把断剑改成断刀" | Truth.amend (二次确认) |
| 直接续写 | (留空回车) | Workflow.next |
| 元提问 | "现在写到哪了?" | 显示进度卡片 |

## 6. 砍掉的旧设计

| 旧元素 | 砍掉理由 |
|---|---|
| 「自动写完本章」按钮 | Auto 模式本身就是这个行为,按钮冗余 |
| 「推荐流程」7 步并列展示 | 用户不需要看 7 步,只需要看 4 步进度 |
| 「下一步」灰色 ghost 按钮 | Auto 不需要,Studio 改成步骤条点击跳转 |
| 「分场景生成」「生成计划」「锁定计划」3 个 ghost 按钮 | 合并为步骤条上的"开始本步骤"主按钮 |
| 「场景卡 / 编辑器 / 审计 / 风格」4 个独立面板 | 改为单条流水线,从上往下读 |
| 「快速开始」首屏卡片 | Auto 模式默认首屏就是输入框,无需独立卡片 |

## 7. 已锁定决定(2026-05-22)

| # | 决定项 | 锁定结论 | 落地说明 |
|---|---|---|---|
| 1 | **默认入口** | **首次创建第一本书时弹一次"喜欢 AI 接管 / 想自己掌控?"二选一,后续记住偏好** | 写入 `userProfile.preferredMode`,新书直接套用;设置页可改 |
| 2 | **AI 卡住/失败暴露** | **弹"AI 卡住了,要不要切到 Studio 接管?"二选一,用户主动选** | 不静默重试(避免 token 浪费),不强切(避免突然中断阅读) |
| 3 | **资料库右抽屉触发** | **智能自动弹**:章末 + 伏笔变动 + 角色关系变化时自动弹一次,3 秒后自动半收起;其余时间手动 hover 触发 | 弹出动画用滑入,不阻塞中央编辑区 |
| 4 | **章节状态枚举** | **`done / draft / active / auto_running` 四态** | `auto_running` 用呼吸灯样式区分,Studio 模式下点击章节看到"AI 正在写第 X 步"灰态卡 |
| 5 | **多设备同步** | **M3 之后再做**,M2 单浏览器登录态先行(localStorage + 后端 session) | M3 引入 ULID 章节版本号 + 增量同步 |
