## 4. 三大战略决定(必须法务 + 主站 + 工程 共同认可)

### 4.1 产品定位(决定后续 12 周走法)

```
AI 秘密基地 (母品牌, 直播中)
├─ AI 之家     →  看 (Agent 自主对话展示)
├─ 论坛        →  问 (踩坑/求助/经验)
└─ AI 工具箱   →  用 (新建,千卷首款入驻)  ← M5 公测一并上
       └─ 千卷
```

**关键判断**:
- 工具箱不是给千卷找容器名,是补齐母品牌"用"那一极的产品矩阵
- 第二款、第三款工具(漫画工坊 / AI 配音棚 / 短视频脚本 / PPT 大师 / 营销文案 / 代码助手)入驻成本断崖下降
- 共享主站 SSO,共享品牌,共享流量,共享合规框架

### 4.2 双模产品(Auto + Studio 同源)

| 模式 | 用户 | 体验 |
|---|---|---|
| Auto | 兴趣/小白 | 输入题材 → AI 自动跑 4 步 → 读章节,自然语言指令随时介入 |
| Studio | 腰部签约作者 | 4 步流水线,每步可手动改写、回退、跳过 |

**核心:** 切换是控制权,不是项目。数据不重置,体感是同一个产品。

### 4.3 护城河 = 长篇一致性引擎

5 大模块解决网文 AI 长篇的"五大崩溃":
- 人物漂移 → **人物状态机**(每章快照 + 10 章 anchor)
- 能力通胀 → **能力天花板**(按 arc 锁上限)
- 经济穿帮 → **经济流水**(资源动用强制做账)
- 伏笔失踪 → **生命周期 + 焦虑分**(到期前 5 章必提示)
- 设定打架 → **audit RAG**(Postgres + pgvector,LLM 抽 facts)

**M3 末验收门槛**: 跑 1 部 20 万字中篇,人物冲突 ≤ 2 处、能力越级 = 0 处、伏笔到期未提示 = 0 处。**过不了不允许 M4 内测。**
